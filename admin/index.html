Administration

Affichez ou masquez un bien, mettez à jour son suivi et réglez le bouton de contact. Chaque enregistrement publie le site en une à deux minutes.

Créer le jeton (une seule fois, 2 minutes)
  1. Connectez-vous à GitHub avec le compte propriétaire du dépôt TheNathorus/suivi.
  2. Ouvrez Settings, Developer settings, Personal access tokens, Fine-grained tokens, puis Generate new token.
  3. Nom : « Suivi admin ». Expiration : celle que vous voulez (un an au plus).
  4. Repository access : « Only select repositories », puis choisissez suivi.
  5. Permissions, Repository permissions, Contents : « Read and write ». Rien d’autre.
  6. Générez le jeton, copiez-le et collez-le ci-dessus.

Le jeton reste dans ce navigateur et n’est envoyé qu’à GitHub. Sans lui, personne ne peut modifier le site depuis cette page. Vous pouvez le révoquer à tout moment dans GitHub.
